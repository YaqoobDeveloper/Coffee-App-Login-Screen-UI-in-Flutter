# Coffee App Login Screen UI in Flutter ☕️✨

A modern and elegant **Coffee App Login Screen UI** built with Flutter, featuring a stylish coffee-themed design with a clean and minimal authentication experience.

This project focuses on creating a polished login interface with beautiful visuals, clean typography, reusable widgets, responsive layouts, and a modern user experience.

## ✨ Features

- ☕ Coffee-themed login screen
- 🎨 Modern and elegant UI design
- 🔐 Clean authentication interface
- 📧 Email input field
- 🔑 Password input field
- 👁️ Password visibility option
- 🧩 Reusable Flutter widgets
- 📱 Responsive layout
- ⚡ Lightweight and fast UI
- 🎯 Clean and organized project structure
- ✨ Smooth and polished user experience

- **Flutter 3.47.2**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Coffee-App-Login-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Coffee-App-Login-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
